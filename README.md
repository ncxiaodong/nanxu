## 框架主体（固定不变）

以下内容为固定框架，修改需与陈辉沟通确认：

### 1. 视觉风格
- **配色**：深蓝 (#0a2b3e) + 暖橙 (#e67e22)
- **字体**：Inter 字体族
- **导航**：固定顶部，毛玻璃效果 (backdrop-filter: blur)
- **按钮**：圆角 40px，橙色主色调
- **卡片**：圆角 1.5rem，悬停上移效果

### 2. 页面结构

- **底部**：版权信息 + 地址 + 微信/GitHub链接

### 3. 核心内容
- **品牌名称**：南序 | 辉旭为简工作室

- **双赛道**：企业降本增效方案 + 个人办公效率提升
- **联系方式**：电话 13576933022 / 邮箱 nanxu_hui@qq.com
